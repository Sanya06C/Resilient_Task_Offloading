# Audited manuscript and reproduction package

The authoritative revised paper is `Resilient_Task_Offloading_IIoT_FINAL.tex` and its compiled PDF. `REVIEWER_RESPONSE.md` maps the nineteen requirements to concrete evidence and records scientific limits. Older manuscript files remain historical and are not authoritative for this revision.

## Reproduce the paper tables (no training required)

From the repository root, with Python 3.12, NumPy and Matplotlib:

```powershell
python publication/recompute_statistics.py
python publication/build_tables.py
```

Or execute `publication/Reproduce_Paper_Tables.ipynb`. It regenerates the same table fragments and figures and checks that the complete five-seed records are present. Core EH tables use `evidence/eh_core_verified.json`, and combined results use `evidence/combined_verified.json`. Inherited EH outputs are preserved separately for provenance but are not the final paired ablation.

The final `.tex` is standalone: tables, verified bibliography entries, and vector plots are inlined for the native LaTeX editor. Compile with an IEEEtran-capable TeX engine, or:

```powershell
tectonic publication/Resilient_Task_Offloading_IIoT_FINAL.tex --keep-logs --keep-intermediates
```

## Regenerate simulations

The frozen QECO checkpoints and saved workload arrays remain in their original repository locations. TensorFlow 2.21.0 with `tf-keras` compatibility is used for this audit; `TF_USE_LEGACY_KERAS=1` is set by the runners. The root `D3QN.py` uses TensorFlow v1 compatibility APIs. Model training and simulation regeneration are deliberately separate from table regeneration.

```powershell
python publication/run_main_validation.py
python run_comparative_baselines_parallel.py --episodes 1000
python publication/verify_counterfactuals.py --episodes 20
python publication/run_eh_validation.py --trace "C:/path/to/dataset.csv"
python publication/battery_capacity_sensitivity.py --trace "C:/path/to/dataset.csv"
```

The baseline runner writes `evidence/comparative_baselines_verified.json`; the published original 1,000-episode baseline summary is `evidence/comparative_baselines_1000.json`. The fresh ten-episode baseline verification does not replace the 1,000-episode summary. A complete regeneration may take substantial time; no truncated run should be labeled complete.

Download the UCLM trace from https://github.com/UCLM-ARCO/energy-harvesting-dataset and verify SHA-256 `9c9d66ef8d9d6507623186067d8f7e3e06dc1029c9e2f2f02f4e55a32418e2a8`. The trace is not redistributed as if it were newly generated by this study. Large traffic captures are external; the already derived `network_stress_profiles/profiles.csv` and `derivation.json` are published. The original traffic dataset DOI is https://doi.org/10.48436/ghdc6-45k78 and its description is https://doi.org/10.1016/j.comnet.2024.110804.

## Interpretation

- The main validation varies independent workload seeds with fixed supplied checkpoints.
- EH inference varies five independent training seeds and averages ten nested episodes per seed.
- The same static energy-preference observation is used in enabled/disabled/combined EH conditions.
- UCLM split allocations are not confused with the short portions actually consumed.
- Terminal SOC/harvest use the last episode only; average cumulative readings are separately named.
- A bounded battery ledger is not an execution-level causality guarantee after depletion.
- The capacity sensitivity reports deterministic fixed-demand reserve thresholds, not hardware lifetime.
- The reference registry audit exposes unverified inherited entries; final cited entries have DOI metadata snapshots.

The target venue and page limit have not been specified. Layout is verified in the compiled IEEE two-column PDF; acceptance or venue-specific compliance cannot be guaranteed.
